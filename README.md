# Báo cáo trực ca – bản màu cam

Đã chỉnh:
- Giữ đúng mục **4. Tồn tại**
- Bỏ nút **Tạo lại báo cáo**
- Đổi **Ca mới** thành **Bắt đầu ca mới**
- Đổi logo sang **màu cam** theo mẫu người dùng thích

## Cập nhật trên GitHub
1. Xóa file `index.html` cũ trên repo (nếu cần) và upload `index.html` mới.
2. Upload thêm:
   - `icon-bao-cao-truc-ca-180.png`
   - `site.webmanifest`
3. Commit changes.
4. Trên iPhone, nếu đã thêm app ra màn hình chính trước đó, hãy xóa icon cũ và **Add to Home Screen** lại để thấy icon mới.
